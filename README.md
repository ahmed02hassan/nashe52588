# خدمات نشا الرقمية + أداة توليد كود الأدمن

المشروع يحتوي على موقعين منفصلين:
1. `public-site/` الموقع العام الثابت.
2. `admin-studio/` أداة مستقلة لإدخال بيانات الخدمات وتوليد سجل JavaScript لنسخه إلى الموقع العام.

## تشغيل المشروع
- فك الضغط.
- افتح `public-site/index.html` في المتصفح لمعاينة الموقع العام.
- افتح `admin-studio/index.html` لاستخدام أداة توليد الكود.
- يفضّل تشغيل المجلدين باستخدام إضافة Live Server في VS Code، خصوصًا لتجربة التنقل والصور.

## إضافة خدمة للموقع
1. افتح `admin-studio/index.html`.
2. أدخل البيانات واضغط «توليد الكود».
3. انسخ سجل الخدمة.
4. افتح `public-site/data/businesses.js`.
5. أضف السجل داخل المصفوفة `window.NASHA_BUSINESSES` مع فاصلة بين السجلات.
6. ضع رابط صورة مناسبًا في `mainImage` و`images`. يمكن استخدام رابط صورة مباشر يسمح صاحبه بإعادة الاستخدام؛ وجود الصورة على الإنترنت لا يعني أن استخدامها مسموح.
7. ارفع ملفات `public-site` إلى استضافتك لتحديث الموقع.

## ملاحظات مهمة
- لا يوجد Backend أو قاعدة بيانات أو نشر تلقائي.
- أداة الأدمن تحفظ مسوداتك محليًا في المتصفح فقط؛ استخدم «تصدير نسخة JSON» للاحتفاظ بنسخة احتياطية.
- الموقع العام يقرأ بيانات الخدمات من `data/businesses.js`.
- روابط الصور الخارجية قد تتوقف أو تمنع العرض؛ الأفضل استخدام روابط مباشرة موثوقة تسمح بإعادة الاستخدام.
- أرقام الخدمات التجريبية غير حقيقية، والبيانات التجريبية موضحة داخل الموقع. استبدلها قبل النشر.
- أداة الأدمن ليست محمية بكلمة مرور؛ لا ترفعها إلى مكان عام إذا كانت بياناتها خاصة.


## شاشة الصدقة الجارية
- أضفنا شاشة افتتاحية تظهر قبل الموقع العام، بتصميم متجاوب للموبايل.
- زر «الدخول إلى المنصة» يخفي الشاشة ويعرض الموقع.
- لتعديل نص الدعاء أو عبارة الإهداء، عدّل عنصر `#memorialScreen` في `public-site/index.html`.
- لتغيير ألوان الشاشة أو تنسيقها، عدّل قسم «شاشة الصدقة الجارية الافتتاحية» في `public-site/assets/css/style.css`.
